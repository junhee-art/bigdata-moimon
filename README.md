# 모임ON — 옥천 평생학습 동아리 일정 탐색기

충북 옥천군 평생교육동아리 공공데이터(CSV)를 분야·키워드로 찾아보는 Streamlit 앱입니다.
동아리마다 다르게 적힌 모임 주기와 시간을 원문과 함께 보여 주고, 명확한 경우에만 요일·시각으로 정리합니다.

## 주요 기능

- **동아리 찾기**: 분야와 키워드로 동아리를 검색합니다.
- **일정 탐색**: 모임 주기·요일·시각을 원문과 함께 구조화해 보여 줍니다.
- **데이터 점검**: 해석이 모호해 검토가 필요한 값을 따로 모아 보여 줍니다.
- **챗봇**: 로컬 Ollama 모델이 CSV에 있는 동아리 정보만으로 질문에 답합니다.

## 실행 방법

Windows PowerShell, Python 3.10 이상 기준입니다.

```powershell
# 가상환경이 없다면 먼저 생성
python -m venv .venv

# 패키지 설치 및 실행
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시된 로컬 주소로 접속하세요(Ctrl + 클릭). 종료는 터미널에서 `Ctrl+C`입니다.

## 프로젝트 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 (동아리 찾기 · 일정 탐색 · 데이터 점검) |
| `schedule_parser.py` | 모임 주기·시간 규칙 기반 파서 (순수 파이썬) |
| `chatbot.py` | Ollama 챗봇 (관련 동아리 검색 · 프롬프트 구성 · 스트리밍 응답) |
| `data/` | 옥천군 평생학습 동아리 시간표 CSV |

## 챗봇 (Ollama)

화면 오른쪽 아래의 **챗봇** 버튼을 누르면 열립니다. 로컬 [Ollama](https://ollama.com)에서 LG AI연구원의 `exaone3.5:2.4b`(한국어·영어 지원) 모델을 사용합니다.

```powershell
ollama pull exaone3.5:2.4b
```

> 챗봇을 쓰려면 Ollama가 실행 중이어야 합니다.

- 질문과 관련된 동아리만 골라 프롬프트에 넣고, 그 목록에 있는 내용으로만 답하도록 지시합니다. 답변 아래에는 참고한 동아리를 함께 표시합니다.
- 연락처·장소·모집 여부·현재 활동 여부처럼 CSV에 없는 정보나 동아리와 관계없는 질문은 모델을 거치지 않고 바로 안내 문구로 답합니다.
- 서버 주소와 모델은 환경 변수로 바꿀 수 있습니다.
  - `OLLAMA_HOST`: Ollama 서버 주소
  - `OLLAMA_MODEL`: 사용할 모델 (기본값 `exaone3.5:2.4b`)
- 첫 질문은 모델을 불러오느라 시간이 걸릴 수 있습니다.
- 컴퓨터 사양이 낮다면 더 작은 `exaone3.5:2.4b` 모델을 사용해 보세요.

## 해석 시 주의사항

- **원문 유지**: 원문은 수정하지 않습니다. 주기·요일·시각이 명확한 경우에만 보조 열로 추출하고, 숫자만 있거나 모호한 값은 추측하지 않고 검토 대상으로 남깁니다.
- **최신성 미확인**: 일정이 지금도 유효한지, 동아리가 현재 활동 중인지는 확인하지 않습니다.
- **통계 해석**: 분야별 동아리 수는 주민 수요를, 결성 연도별 동아리 수는 현재 활동량을 뜻하지 않습니다.
- **제공하지 않는 정보**: 지역·장소·연락처·모집 여부는 CSV에 없으므로 지도나 가입 안내 기능은 없습니다.
- **챗봇 한계**: 작은 모델이라 목록 일부만 답하거나 표현이 어색할 수 있습니다. 정확한 일정은 원문을 확인하세요.
